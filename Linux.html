CHAPTER 01

内核与系统概览

Linux 操作系统内核直接控制内存和其他硬件。Linux 命令大小写敏感，这是初学者最容易忽略的规则。

CHAPTER 02

标准流与快捷键

执行一个 Shell 命令行时，通常自动打开三个标准文件。

三个标准文件

  • stdin 标准输入文件 —— 进程从标准输入文件中得到输入数据
  • stdout 标准输出文件 —— 将正常输出数据输出到标准输出文件
  • stderr 标准错误输出文件 —— 将错误信息送到标准错误文件中

命令行重要快捷键

  • Tab 命令补全
  • Ctrl+a 光标移动到命令行首
  • Ctrl+c 强行终止当前程序
  • Ctrl+d 输入结束或退出终端
  • Ctrl+e 光标移动到命令行尾
  • Ctrl+l 清屏
  • Ctrl+s 暂停，任意键恢复运行
  • Ctrl+z 挂起当前进程至后台，fg 命令恢复前台
  • Alt+Backspace 向前删除一个单词
  • Ctrl+Shift+c 复制
  • Ctrl+Shift+v 粘贴

CHAPTER 04

通配符与匹配

  • * 匹配任意个字符
  • ? 匹配任意一个字符
  • [list] 匹配其中的任意单一字符
  • [^list] 匹配其中所有字符以外的任意单一字符
  • [c1-c2] 匹配范围内的任意单一字符，如 [0-9] [a-z]
  • {string1,string2,...} 匹配其中任意一个字符串
  • {c1..c2} 匹配范围内全部字符，如 {1..10}
CHAPTER 05

用户与用户组管理

一般登录系统时以普通账户登录。创建用户需要root权限，两大前提：当前登录用户密码、当前用户属于sudo用户组。

  • useradd 只创建用户，不会创建用户密码和工作目录，需要使用 passwd <username> 设置新用户密码
  • sudo adduser [username] 可以添加用户到系统，同时默认为新用户在/home目录下创建一个工作目录
  • su [user] 仅切换用户
  • su - [user] 切换用户同时用户的环境变量和工作目录也会跟着改变成目标用户所对应的
  • sudo passwd [user] 设置用户密码
  • groups [user] 查看用户所属用户组
  • sudo usermod -G sudo [user] 为用户添加所属用户组
  • sudo deluser [user] 删除用户
  • sudo deluser [user] --remove-home 删除用户同时删除工作目录
  • sudo groupdel [group] 删除用户组
CHAPTER 06

文件权限详解

Linux 里面一切皆文件。使用 ls -l [file] 查看文件权限。

文件类型标识

第一个字母代表文件类型：

  • d 目录
  • l 软链接
  • b 块设备
  • c 字符设备
  • s 网络嵌套字
  • p 管道
  • - 普通文件

权限字符串

第二个字母开始，权限字符串三个一组，依次为所有者权限、组权限、其他人权限，顺序均为 rwx。有相应权限表示成相应字母，不具有相应权限用 - 表示。

  • r 读取权限，数字代号 4
  • w 写入权限，数字代号 2
  • x 执行或切换权限，数字代号 1

权限变更命令

  • sudo chown [user] [file] 变更文件所有者
  • sudo chmod [r][w][x] [file] 二进制数字表示法修改权限
  • sudo chmod [权限范围][+·-·=][权限设置] [file] 加减赋值法修改权限

权限范围：u 所有者、g 所属组、o 其他人、a 所有人

-R 参数：递归处理，指令目录下的所有文件及子目录一并处理

  • <权限范围>+<权限设置> 开启权限范围的文件或目录的该选项权限设置
  • <权限范围>-<权限设置> 关闭权限范围的文件或目录的该选项权限设置
  • <权限范围>=<权限设置> 指定权限范围的文件或目录的该选项权限设置
CHAPTER 07

目录与文件基本操作

  • touch [file] 新建空白文件；更改已有文件的时间戳。不加任何参数只指定一个文件名创建空白文件，不会覆盖已有同名文件，也可以同时指定时间戳
  • mkdir [dir] 新建空目录
  • mkdir -p [dir] 创建多级目录
  • cp [file] [dir] 复制文件
  • cp -r [dir] [dir] 复制目录
  • rm [file] 删除文件
  • rm -f [file] 强制删除文件
  • rm -r [dir] 删除目录
  • rm -rf [dir] 强制删除目录
  • mv [file] [dir] 移动文件
  • mv [oldfn] [newfn] 重命名文件
  • cat [file] 正序打印文件
  • cat -n [file] 显示行号
  • tac [file] 倒序打印文件

nl：更专业的行号打印命令

  • -b 指定添加行号的方式：-b a 无论是否空行，-b t 只列出非空行编号
  • -n 设置行号的样式：-n ln 最左端显示，-n rn 最右边显示且不加0，-n rz 最右边显示且加0
  • -w 行号占用的位数，默认6位

分页与查看

  • more [file] 分页查看文件，只能向一个方向滚动
  • less [file] 分页查看文件，基于more和vi，功能更强
  • head [file] 只查看文件头10行
  • tail [file] 只查看文件尾10行
  • tail -n [num] [file] 只查看文件尾几行
  • tail -f [file] 不停地读取某个文件的内容并显示，动态查看日志，实时监视
  • file [file] 查看文件类型
CHAPTER 08

环境变量

在当前进程的子进程有效则为环境变量。按变量生存周期划分，Linux变量分为两类：修改配置文件变量永久生效；使用export声明，变量在关闭shell时失效。

  • declare [var] 预声明变量，创建指定类型变量如数组时会用到
  • var=[value] 变量赋值
  • echo $[var] 读取变量
  • set 显示当前Shell所有变量，包括内建环境变量、用户自定义变量
  • env 显示与当前用户相关的环境变量，让命令在指定环境中运行
  • export 显示从Shell中导出成环境变量的变量，将自定义变量导出为环境变量
  • export PATH=$PATH:[absolute path] 临时添加自定义路径到环境变量
  • unset [var] 删除变量

配置文件

用户home目录中包含Shell启动默认执行的配置脚本，以初始化环境。zsh配置文件 .zshrc，Bash配置文件 .bashrc

env-config.sh
# 永久添加自定义路径到环境变量
echo "PATH=$PATH:[absolute path]" >> .zshrc
source .zshrc      # 立即生效

# 重定向符号说明
# >> 将标准输出以追加的方式重定向到一个文件中
# >  将标准输出以覆盖的方式重定向到一个文件中
# 指定文件不存在则创建新的文件
CHAPTER 09

文件搜索

  • whereis 只能搜索二进制文件(-b)、man帮助文件(-m)、源代码文件(-s)
  • which 确定是否安装指定程序，从PATH环境变量指定路径搜索命令返回第一个结果
  • find [path] [option] [action] 通过文件类型文件名进行查找，根据文件的属性如时间戳权限等进行搜索
search-examples.sh
sudo find /etc -name interfaces   # 从/etc目录中查找interfaces文件
find ~ -mtime 0                    # 查找home目录中24小时内改动文件
find ~ -newer /etc                 # 查找home目录中比/etc目录新的文件
CHAPTER 10

命令执行与管道

命令执行顺序控制

  • 简单的顺序执行：; 间隔命令
  • 有选择的执行：which [command] && [lo] [comand] ... 通过逻辑与 && 和逻辑或 || 组合选择性执行
  • echo $? 获取上次命令返回结果

管道 (|)

一种通信机制，用于进程间的通信，也可通过socket进行网络通信。将前一个进程的输出(stdout)作为下一个进程的输入(stdin)。

  • grep [option] [regular expression] [file] 结合正则表达式实现复杂却高效的匹配查找
  • wc [option] [file] 统计并输出文件中行(-l)、单词(-w)、字节(-c)、字符(-m)的数目
  • cat [file] | sort 默认字典排序
  • cat [file] | sort -r 反转排序
  • cat [file] | sort -t '[sign]' -k [num] 分隔符分割后按特定字段排序
  • history | sort | uniq 去重输出
  • history | sort | uniq -dc 输出重复行和重复次数
CHAPTER 11

文本处理

  • tr 删除文本信息中的某些文字
  • echo 'hello shiyanlou' | tr -d 'olh' 删除所有的olh
  • echo 'hello' | tr -s 'l' 连续并重复的字符ll去重为一个l
  • echo 'input some text here' | tr '[:lower:]' '[:upper:]' 转换为大写或小写输出
  • cat [file] | col -x 将Tab转换为空格
  • cat [file] | col -h 将空格转换为Tab（默认）
  • join -t '[sign]' [file] [file] 默认将两个文件以指定分隔后第一字段相同的那一行以指定分隔符合并在一起
  • join -t '[sign]' -1 2 [file] -2 3 [file] 分别比对第2和第3个字段
  • paste 不对比数据简单地将多个文件合并一起，以Tab隔开
  • paste -d '[sign]' [file]... 指定合并分隔符
  • paste -s [file]... 合并到下一文件时分行
CHAPTER 12

数据流重定向

描述符 设备文件 说明
0 /dev/stdin 标准输入
1 /dev/stdout 标准输出
2 /dev/stderr 标准错误
  • cat [file] 1>[file] 2>&1 将标准错误重定向到标准输出，再将标准输出重定向到文件
  • cat [file] &>[file] 将标准错误和标准输出同时重定向到文件
  • exec [num]>[file] 永久重定向直至退出当前shell
  • cat [file] 1>/dev/null 2>&1 完全屏蔽命令的输出

空设备 /dev/null 用于丢弃不需要的输出流，读取立即得到EOF。

CHAPTER 13

进程管理

基本概念

  • 程序(procedure)：执行一系列有逻辑有顺序结构的指令
  • 进程(process)：程序在一个数据集合上的一次执行过程

进程的特征

  • 动态性：进程的实质是一次程序执行的过程，有创建撤销等状态的变化，而程序是一个静态的实体
  • 并发性：进程可以做到在一个时间段内有多个程序在运行中，程序只是静态的实体不存在并发性
  • 独立性：进程可以独立分配资源，独立接受调度，独立地运行
  • 异步性：进程以不可预知的速度向前推进
  • 结构性：进程拥有代码段、数据段、PCB(进程控制块，进程存在的唯一标志)

并发 vs 并行

  • 并发：在一个时间段内，宏观有多个程序都在有条不紊的执行，每一瞬间只有一个在执行，只是在一段时间有多个程序都执行过
  • 并行：在每一个瞬间都有多个程序都在同时执行，必须多CPU(核)

线程与进程分类

线程：操作系统进行运算调度的最小单位，包含在进程之中是进程中的实际运作单位。一条线程指的是进程中一个单一顺序的控制流，一个进程中可以并发多个线程并且每条线程并行执行不同的任务。因为线程中几乎不包含系统资源所以执行更快更有效率。

  • 以进程的功能与服务的对象来分：用户进程、系统进程
  • 以应用程序的服务类型来分：交互进程、批处理进程、守护进程

系统调用与特殊进程

  • fork()：为当前的进程创建一个新的进程，新的进程则是其子进程，子进程除了父进程的返回值和PID以外与父进程相同
  • exec()：切换子进程中的执行程序，替换其从父进程复制过来的代码段与数据段
  • 僵尸进程：放弃了几乎所有内存空间，没有任何可执行代码，不能被调度，仅在进程列表中保留一个位置，记载该进程的退出状态等信息供其父进程收集从而释放它。但Linux能使用的PID有限，如果系统中存在大量僵尸进程会因为没有可用的PID从而导致不能产生新的进程
  • 孤儿进程：父进程非正常的结束未能及时收回的仍在运行的子进程。孤儿进程一般会成为init的子进程，由init来做善后处理

进程控制

  • ls & 通过&让命令在后台中运行
  • jobs 查看被停止并放置在后台的工作
  • ubuntu在zsh中需要%，在bash中不需要
  • fg %[jnum] 将后台的工作拿到前台
  • Ctrl+z 使工作停止放置在后台
  • bg %[jnum] 让其在后台运作
  • ps aux 罗列出所有的进程信息
  • ps -l 显示bash相关的进程信息
  • kill -9 [pid] 强制杀死进程
